Key Tuner Security Policy

Overview

Key Tuner is a secure password generation tool using Rust/WebAssembly. This security policy outlines the project's security measures, vulnerability reporting process, and security guidelines for users.

Security Design Principles

Key Tuner is developed based on the following security design principles:

  • Client-side Processing: All password generation is performed within the user's browser, and generated passwords are not sent to any server.
  • WebAssembly Isolation: Core functionality is implemented in Rust and compiled to WebAssembly, ensuring high performance and security.
  • Open Source: The code is published under the GPL-3.0 license, allowing for community auditing.
  • Minimal Dependencies: External dependencies are kept to a minimum to reduce the risk of supply chain attacks.

Vulnerability Reporting Process

If you discover a security vulnerability, please report it using the following procedure:

  • Contact: Report security-related issues directly to shun@getto.systems.
  • Information Provision: Include details of the vulnerability, steps to reproduce, and potential impact.
  • Response Time: We typically provide an initial response to reported vulnerabilities within 48 hours.
  • Remediation Process: Confirmed vulnerabilities are addressed based on priority, and fixes are released.

Security Update Policy

  • Critical Vulnerabilities: For critical security vulnerabilities, we aim to provide a fix within 72 hours.
  • Notifications: Security updates are announced on the project repository and website.
  • Version Management: All security updates are properly versioned according to semantic versioning principles.

Data Processing and Privacy

  • No Data Collection: Key Tuner does not collect or store user data.
  • Local Processing: All password generation is processed locally in the user's browser.
  • No Server Communication: Generated passwords and settings are not sent to any server.

Third-Party Dependencies

  • Dependency Auditing: All third-party dependencies are regularly audited to ensure they are free from known vulnerabilities.
  • Principle of Least Privilege: Dependencies are limited to the minimum necessary functionality.
  • Update Policy: Updates to dependencies that include security fixes are applied with priority.

Security Best Practices for Users

When using Key Tuner, we recommend the following security best practices:

  • Use the Latest Version: Always use the latest version of Key Tuner.
  • Password Management: We recommend storing generated passwords in a secure password manager.
  • Browser Security: Use an up-to-date browser and apply security updates.
  • Trusted Source: Only download Key Tuner from the official website (https://key-tuner.getto.systems).

Responsible Disclosure

We ask security researchers to responsibly disclose any vulnerabilities they discover. Please do not disclose vulnerability details publicly until the vulnerability has been fixed and users have been notified. Appropriate credit will be given for cooperative disclosure.

Contact Information

For security-related inquiries, please use the following contact information:

  • Email: shun@getto.systems
  • Please include "[Key Tuner Security]" in the subject line.

This security policy is reviewed regularly and updated as needed.
